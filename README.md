# 单词积累软件设计文本

定位：英语积累软件

功能细节：

**记背单词部分**

1. 以树图（思维导图）的形式呈现单词。每个单词下可以*链接*一个或多个单词，点击单词后能够出现其详细释义、例句、用法等与用户自己的笔记。
2. 用户可新建一个单词的*类别*，并在其中进行功能1中的操作。
3. 用户可对某个类中的全部或一些单词（导出时类别中的单词成列表，用户在其中选择）进行*导出*为某一*格式*。

*链接*：用户在对某两个单词进行连接时，需要填写两个单词进行连接的原因（如词根/词缀相同，意思相近/相反等）

*类别*：即给单词新建一个组（在侧边栏中添加）

*导出*：用户可选择某一个类别中的所有或一些单词（可对单词的词根、词缀、释义、词性、与该类中某个单词的链接原因进行筛选）来进行不同格式的导出。

*格式（预设格式）* 如下：

- 默写格式：A4大小，等分为4列，分别为单词本体、空列（默写中文列）、单词中文释义与词性、空列（默写英文列）。每一行为标准英语四线三格，列与列之间有细虚线间隔。
- 打印格式：A4正常大小，正常排列单词（词与词之间空格，上下列单词首位对齐）。
